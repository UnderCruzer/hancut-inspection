# 결정 기록

왜 그렇게 했는지를 남긴다. 발표와 면접에서 "다른 선택지는 없었나"에 답하는 재료다. 결정이 바뀌면 지우지 말고 **아래에 새 항목으로 추가**한다.

---

## D1. 성능을 정확도가 아니라 판정 3구간으로 정의한다

**결정** — `자동 준수 / 확인 필요 / 자동 미준수`로 나누고, 놓침률 상한을 먼저 정한 뒤 확인 필요 비율을 최소화한다.

**이유** — 두 실수의 값이 다르다. 미준수를 놓치면 화재 시 설비가 작동하지 않고, 준수를 미준수로 잡으면 점검원이 한 번 더 보면 된다. 하나의 정확도 숫자는 이 차이를 표현하지 못한다.

**버린 선택지** — 단일 임계값 + F1. 구현은 간단하지만 "얼마나 안전한가"를 말할 수 없다.

**결과** — `ml/hancut/eval/zones.py`, `server/app/judgment.py`

---

## D2. LLM에는 사진을 주지 않는다

**결정** — 판정은 비전 모델이 하고, LLM은 구조화된 판정 결과만 받아 점검표 문장을 쓴다.

**이유** — 법정 서류다. LLM이 사진을 보고 직접 판단하면 근거 없는 내용이 서류에 들어갈 수 있다. 입력을 판정 결과로 제한하면 지어낼 재료 자체가 없다.

**버린 선택지** — 멀티모달 모델에 사진과 양식을 함께 주고 점검표를 한 번에 작성. 구현은 짧지만 검증이 불가능하다.

---

## D3. 원본이 아니라 640px 서브셋으로 학습한다 (B안)

**결정** — 8종만 받아 640px로 한 번 축소한 뒤 학습한다.

**이유** — 원본은 장당 평균 1.58MB인 고해상도지만 모델은 640px로 학습한다. 매 에폭 디코딩하면 GPU가 아니라 CPU가 병목이다. 한 학기 비용 추정이 약 $1,300에서 약 $170으로, 학습 1회가 약 85시간에서 약 7시간으로 줄어든다.

**주의** — 학습 시간은 추정치다. W3에 1에폭을 실측해 다시 계산한다.

**결과** — `ml/hancut/data/resize.py`, `docs/data.md`

---

## D4. 모델이 없으면 가짜 결과 대신 503을 반환한다

**결정** — 판정 API는 모델이나 임계값이 없으면 503으로 응답한다.

**이유** — 개발 중 더미 응답을 돌려주면 앱과 측정이 그 값을 진짜처럼 다루게 된다. 없을 때는 없다고 말하는 쪽이 안전하다.

**결과** — `server/app/main.py`, `server/tests/test_api.py`

---

## D5. 라벨 파서를 스키마 확인 전에 쓰지 않는다

**결정** — 라벨 JSON 파서는 샘플 데이터로 구조를 확인한 뒤(#5) 작성한다.

**이유** — 준수/미준수가 박스 단위인지 이미지 단위인지에 따라 파서뿐 아니라 모델 구조(E1)까지 갈린다. 추측으로 쓰면 나중에 두 번 고친다.

---

## D6. 혼자 하므로 범위를 줄인다

**결정** — E5(점검표 초안)와 E6(연한 OCR) 중 하나만 한다. E7, 앱 오프라인 동기화, PDF 출력은 제외하고 시설은 8종으로 고정한다.

**이유** — 4인 기준 계획을 1인이 그대로 하면 전부 미완성으로 끝난다. E1–E4와 점검 앱은 결론을 만드는 축이라 유지한다.

**어떻게 말할 것인가** — 발표에서 줄인 사실과 이유를 밝힌다. 숨기고 미완성으로 끝나는 것보다 낫다.

**결과** — `docs/plan.md` 범위 조정표, 이슈 #10

---

## D7. Jira 대신 GitHub Projects를 쓴다

**결정** — 교안이 요구한 협업 도구 중 Jira를 GitHub Projects로 대체한다.

**이유** — 1인 프로젝트에서 이슈 추적기를 두 곳으로 나누면 한쪽이 방치된다. 코드·이슈·보드가 한곳에 있는 편이 기록이 남는다. Git과 Slack은 그대로 쓴다.

**발표에서** — 대체했다는 사실과 이유를 한 줄로 밝힌다.

---

## D8. 소방시설 주제를 유지하고 실제 상태 라벨로 범위를 정한다

2026-09-24 사용자 지시. 제품 검사 전환 취소. Weqaa를 우선 검증하며 소화기의 압력계 상태·부식을 초기 대상으로 한다. D3의 용량/시간 추정과 D6의 8종 범위는 현재 적용하지 않는다. 해외 이용 조건과 전체 export 검사를 마친 데이터만 미국 AWS 학습에 사용한다. 미검출을 정상/부품 누락으로 자동 판정하지 않는다. 같은 영상/개체는 분할 간 공유하지 않는다. 근거: fire-dataset-review.md.
