# 현재 데이터 — 보안검색 X-ray

2026-09-24 범위 전환(#12). 학교 AWS 계정이 `us-east-1` 고정이라 AI Hub 데이터는 국외 반출 합의 없이 쓸 수 없다.
X-ray 보안검색 공개 벤치마크는 반출 제약이 없고 학술 목적 이용이 명시돼 있어 이 계정에서 그대로 쓸 수 있다.

## 받을 대상

| 데이터셋 | 장수 | 클래스 | 라벨 | 출처 |
|---|---|---|---|---|
| PIDray | 47,677 | 12종 | bbox + segmentation mask | https://github.com/bywang2018/security-dataset |
| SIXray | 1,059,231 | 6종 (hammer는 표본 부족) | 이미지 단위 + 일부 bbox | https://github.com/MeioJane/SIXray |
| OPIXray | 8,885 | 칼 5종 | bbox | 가림 특화, 보조 검증용 |
| HiXray | 45,364 | 8종 | bbox | 예비 후보 |

**PIDray를 먼저 받는다.** 47k로 작고, 마스크까지 있고, 무엇보다 **서로 다른 장비 3대**로 찍혔다.
장비가 임계값에 미치는 영향을 측정할 수 있는 건 현재 이것뿐이다.

SIXray는 위해물품이 든 사진이 전체의 1% 미만인 극단적 불균형 벤치마크다.
전량을 받지 않고 양성 전량 + 음성 층화 표본으로 서브셋을 만든다. `ml/hancut/data/subset.py`를 그대로 쓴다.

## 이용 조건

둘 다 **학술 목적 한정, 상업적 이용 불가, 재배포 금지**다. 국외 반출 조항은 없다.

- 원본 이미지와 라벨을 저장소에 넣지 않는다. `.gitignore`의 `/data/`, `ml/data/`, `server/data/` 규칙을 유지한다.
- 논문/발표에 쓸 때 원 논문을 인용한다. SIXray는 UCAS PRIS 연구실, PIDray는 해당 저장소의 인용 양식을 따른다.
- 발표자료에 원본 이미지를 넣을지는 각 저장소의 조건을 다시 확인하고 정한다. 확인 전에는 집계 지표와 직접 만든 도식만 쓴다.

## 왜 이 데이터인가

이 업무는 **두 종류의 실수 값이 다르고, 그 사실이 제도에 이미 들어가 있다.**
TSA/FAA 인증은 탐지율과 오경보율 두 상한을 동시에 요구한다.
`fit_thresholds(max_miss_rate, max_false_alarm_rate)`가 이미 그 형태다.

비교 기준선도 존재한다. 인간 판독관 정확도는 최적 조건에서 80~90%다(EU JRC).
"모델이 사람보다 낫다"가 아니라 **"놓침률을 사람 수준 아래로 묶으면 몇 %를 사람이 안 봐도 되나"**를 묻는다.

## 받은 뒤 가장 먼저 확인할 것

1. **정답의 단위.** 라벨이 박스 단위다. 이미지 단위 "위해물품 있음/없음" 정답을 어떻게 정의할지 먼저 정해야
   `zones.py`에 점수를 물릴 수 있다. 박스 점수의 최댓값을 쓸지, 보정된 집계를 쓸지가 E1의 갈림길이다.
2. **장비별 장수와 분포.** PIDray 장비 3종이 각각 몇 장이고 클래스 분포가 같은지. 장비 교차 검증의 설계가 여기서 갈린다.
3. **공식 split의 누수.** 같은 가방을 여러 각도로 찍은 사진이 train/test에 나뉘어 있지 않은지 확인한다.
   Weqaa에서 같은 영상 프레임이 섞인 사례를 이미 겪었다. 공식 분할을 그대로 신뢰하지 않는다.
4. **SIXray 양성 장수.** 논문상 수천 장 수준으로 알려져 있으나 실제 수치는 받아서 센다.

이 네 가지가 확인되기 전에는 라벨 로더를 쓰지 않는다. D5와 같은 이유다.

## 쓰지 않는 데이터

AI Hub 518 — 국외 반출 합의 없음. `docs/archive-aihub/` 참조.
Weqaa — 반출 제약은 없으나 핀·호스 라벨이 누락 정답이 아니고 split 누수가 있다. `docs/archive-weqaa/` 참조.
VisA / Real-IAD — 제품 결함 검사로의 전환은 취소됐다. `docs/archive-visa/`, `docs/archive-realiad/` 참조.

기존 파일을 자동 삭제하지 않는다.
