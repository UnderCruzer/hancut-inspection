# 현재 데이터 — 소방시설 상태 점검

2026-09-24 사용자 지시에 따라 소방시설 주제를 유지한다. Weqaa가 우선 검증 후보다.
[라벨·이용조건 조사](fire-dataset-review.md)에 실제 확인 근거와 한계를 기록했다.

## 받을 대상

- https://universe.roboflow.com/cv-project-g2qeh/weqaa/dataset/18
- v18: 증강 포함 7,664장, 640×640. 프로젝트 원본 3,592장.
- 원본 이미지와 라벨을 함께 받는다. 검출 기준선은 YOLO 형식, polygon 보존이 필요하면 segmentation/COCO export 구조부터 확인한다.
- Download에서 로그인 요구를 확인했다. 전체 ZIP은 아직 확보하지 않았다. 실제 용량/클래스 수/누락 라벨은 미확인이다.
- CC BY 4.0 표시 및 worldwide 라이선스에 근거하여 미국 AWS 이용 후보로 판단한다. 출처·라이선스·변경 사항을 보존한다.

## 중요한 라벨 한계

직접 상태 대상은 압력계 정상/이상과 부식. 핀·호스 존재 라벨은 누락 정답이 아니며 날짜 라벨 위치는 유효기간 정답이 아니다.
실제 v18 gauge_bad polygon은 공개 Raw Data로 확인했다. 나머지 클래스 및 분포는 전체 export에서 다시 확인한다.
프로젝트 개요의 옛 8개 클래스와 논문의 6개 클래스만 보고 class ID를 하드코딩하지 않는다.

## 다운로드 후 순서

1. 라이선스/README/클래스/파일 체크섬/용량 기록.
2. 영상 접두사와 원본 ID를 이용한 중복·그룹 확인. 같은 영상이 train/valid/test에 섞인 공개 목록을 발견했으므로 공식 분할을 그대로 신뢰하지 않는다.
3. 독립 원본 그룹 기준 분할 및 클래스별 표본 수 확인; 시험셋 고정.
4. 학습 기준선 → 모델 출력 정의·보정 → 평가 CLI → 앱 점검 기록.

## 기존 데이터 처리

AI Hub 518은 해외 반출 합의가 없어 미국 AWS에 사용하지 않는다. VisA/Real-IAD는 현 프로젝트 학습 대상으로 사용하지 않는다.
기존 파일을 자동 삭제하지 않는다. 이전 문서는 archive-aihub/, archive-visa/, archive-realiad/에 보관한다.
이전 8종·8만 장·6GB·7시간 추정은 Weqaa에 적용되지 않는다. 학습비용/시간은 새 기준선에서 실측한다.
