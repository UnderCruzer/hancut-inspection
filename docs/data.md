# 데이터

## 출처

AI Hub **다중밀집시설 및 주거시설 화재 안전 데이터** (dataSetSn=518, 2021 구축 · 2022.07 개방)
https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=518

| 항목 | 내용 |
|------|------|
| 규모 | 608,280장 — 준수 404,140 / 미준수 204,140 · 약 962GB |
| 구성 | 현장설치환경 이미지 + 현장동영상 이미지, 학습·검증·시험 분할 |
| 시설 | 24종 (`ml/configs/facilities.json`) |
| 미준수 사유 | 부식, 시인성부족, 변형손상, 헤드설치불량, 감열살수방해, 요소부족, 장애물존치 등 |
| 라벨 | 바운딩박스(4점 좌표) + 클래스, JSON |
| 조건 | 내국인 신청·승인 필요, 분할 압축, 리눅스(또는 WSL) 다운로드 권장 |

## 받기

1. AI Hub 로그인 → 데이터셋 페이지에서 다운로드 신청
2. **샘플(경량) 데이터부터** 받아 아래 W2 확인 항목을 먼저 본다
3. 승인 후 `aihubshell`로 1단계 8종 폴더만 선택해 받는다 — 전체를 받지 않는다

```bash
curl -o aihubshell https://api.aihub.or.kr/api/aihubshell.do && chmod +x aihubshell
```

## 학습 전략 · B안

| | A · 원본 전체 | B · 8종 · 640px |
|---|---|---|
| 규모 | 약 962GB | 8만 장 × 약 70KB ≈ 6GB |
| 학습 1회 (추정) | 약 85시간 | 약 7시간 |
| 한 학기 AWS (추정) | 약 $1,300 | 약 $170 |

장당 평균 1.58MB 원본을 `ml/hancut/data/resize.py`로 **한 번만** 640px 축소한다. 학습 속도는 추정치이므로 W3에 1에폭 실측 후 다시 계산한다.

AWS를 쓸 경우: 학습이 끝나면 인스턴스 중지, EBS는 중지해도 과금, **AWS Budgets 알림을 먼저 설정**.

## W2 확인 항목

- [ ] 준수/미준수가 **박스 단위 속성**인지 **이미지 단위**인지 → 모델 구조(E1)와 파서 설계가 갈린다
- [ ] 미준수 사진이 **실제 현장**인지 **연출 촬영**인지 샘플 검토
- [ ] 파일명 규칙 (예: `01_001_0001_O_F_00000001.jpg`) 필드 의미
- [ ] 이용약관의 재배포·클라우드 업로드 조건
- [ ] 라벨 JSON 스키마 → `ml/hancut/data/`에 파서 작성

라벨 파서는 스키마를 확인한 뒤 작성한다. 추측으로 먼저 쓰지 않는다.
