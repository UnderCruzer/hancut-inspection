# 한컷검수 — Real-IAD 제품 검수 AX (1인)

2026-09-24 사용자 승인으로 AI Hub 소방시설에서 Real-IAD 제품 결함 검사로 전환.
이전 계획은 archive-aihub/에 보관한다. 기존 소방시설 법정 점검/OCR 요구는 현 범위에서 제외한다.

## 서비스

PCB 사진 → 결함 위치 및 점수 → 자동 정상/사람 확인/자동 결함 → 담당자 확인·정정 → 검수 기록 CSV.
목표는 결함 놓침률 상한 아래 사람이 확인하는 비율과 기록 시간을 줄이는 것이다.
출시 가능한 범용 검사기가 아닌 공개 데이터 기반 검증용 프로토타입으로 발표한다.

## 범위와 모델링

- 우선 pcb, 이후 audiojack/usb/switch를 초기 확장 후보로 삼는다. 제품별 표본 수를 확인한 뒤 최종 범위를 확정한다. 초기 단계는 데이터셋 사진 업로드, 스마트폰 촬영 일반화는 별도 검증.
- 기준선: 정상 이미지 특징을 이용한 PatchCore 계열 이상 탐지. 비교 모델/해상도 변경은 한 번에 하나씩.
- 영상 단위 AUROC, 결함 재현율, 위치 마스크 평가, 3구간 놓침률·검토율·오경보율 측정.
- 원시 이상 점수는 확률이 아니다. 기존 CLI의 0~1 점수 계약에 맞게 검증 데이터에서만 보정기를 적합하고 저장한다. 단순 정규화 값을 확률로 주장하지 않는다.
- 공식 Real-IAD JSON 분할을 읽어 시험 데이터는 고정한다. 기존 CLI가 요구하는 양 클래스 검증셋 확보 방식을 먼저 결정한다. 필요 시 시험 풀을 검증/최종시험으로 분할하고 이를 공식 벤치마크와 다른 자체 프로토콜로 명시한다.
- 작은 이상 표본에서 1% 상한은 신뢰성 보장이 아니다. 분모와 놓친 개수를 함께 보고한다.

## 현재 코드 상태

평가 CLI/서버/앱 골격은 재사용. 모델·데이터 로더·화면 용어 전환은 아직 미구현.
ml/configs/facilities.json은 이전 소방시설 설정이므로 Real-IAD 실행에 사용하지 않는다.
기존 wire 값 auto_compliant/auto_noncompliant는 향후 정상/결함 UI로 매핑한다.
원본·가중치·API 키는 Git에 넣지 않는다. 이미 수행한 테스트 86개는 기반 코드 테스트이며 VisA 모델 성능이 아니다.

## 다중 시점 실험

동일 제품의 1개 시점과 5개 시점 결합 결과를 제품 단위로 비교한다. 동일 제품 ID의 분할 누수를 금지한다. 이미지 수를 독립 표본 수로 쓰지 않는다. 결함 마스크 위치 지표와 제품 단위 놓침률을 함께 기록한다.
