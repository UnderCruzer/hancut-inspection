# 데이터 확보·이용 조건 확인 (#1, #2)

확인일: 2026-09-22. 공개 웹 안내 확인 결과이며, 사용자 계정 승인 화면은 확인하지 않았다.

## #1 확보 상태

- 공식 데이터셋 518의 공개 페이지와 샘플 제공 안내 확인.
- 개인 이용 신청 여부, 승인 상태, 실제 샘플 다운로드: 미확인. 완료로 처리하지 않는다.
- 1인 작업: 승인받은 본인 계정으로 내려받아 사용한다. 팀원 전달 절차는 삭제한다.
- 파일 목록에서 대응 이미지/라벨의 filekey와 크기를 확인한 후 선택 다운로드한다.
- 8종별 개별 압축파일 제공 여부는 미확인이다. 8만 장·6GB는 전처리 후 목표/추정치다.

## #2 이용 조건

공식 이용정책은 출처 및 NIA 사업결과 표시, 무승인 제3자 제공 제한,
국외 이용 주체 및 국외 반출의 별도 합의를 명시한다.
기존 오류에 나온 AWS `us-east-1` 사용 시 국외 반출 조건을 확인해야 한다.
이전의 미국 리전 직접 다운로드 안내는 정정한다. 별도 합의 없이 진행하지 않는다.

국내 리전의 본인 전용 비공개 저장소 이용을 준비 후보로 삼되, AWS 사용 전반에 대한
명시적 허용은 이 공개 안내만으로 확정하지 못했다. 학교 계정에서 국내 리전이 가능한지도 미확인이다.
원본 사진의 발표자료 삽입 및 이미지 ID만 포함한 목록의 공개 허용 범위 역시 확인되지 않았다.
이 항목들은 #2에 남겨 데이터 제공기관의 답변/신청 시 조건을 확인한다.
공개 보고서는 우선 집계 지표와 직접 만든 도식으로 구성한다.

FAQ는 학습 결과 모델·서비스·연구 성과 활용과 원본/단순 가공 데이터의 재배포를 구분한다.
원본 이미지를 넣은 PPT까지 자유롭게 공개 가능하다는 뜻으로 확대 해석하지 않는다.

출처 표기 예시: 이 연구는 한국지능정보사회진흥원(NIA) 사업으로 구축된
AI Hub 「다중밀집시설 및 주거시설 화재 안전 데이터」를 활용하였다.

## 사용자 화면/제공기관 확인이 필요한 항목

1. 본인 신청/승인 여부와 신청 시 적용된 조건.
2. 국내 AWS 비공개 EC2/EBS 저장·학습 허용 여부 및 미국 리전 반출 합의 절차.
3. 캡스톤 발표자료의 소량 원본 이미지와 이미지 ID 목록 공개 허용 범위.

외부 문의는 발송하지 않았다. 해당 확인은 데이터 없이 가능한 #9 구현과 독립적으로 진행한다.
