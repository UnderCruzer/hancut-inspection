# 한컷점검 — 소방시설 사진 점검 AX (1인)

2026-09-24 정정: 사용자는 소방시설 주제를 유지한다. VisA/Real-IAD 제품 검사 전환을 취소한다.
현재 범위는 소화기이며 Weqaa를 우선 검증한다. [데이터 검토](fire-dataset-review.md)가 이전 계획보다 우선한다.

## 서비스

소화기 사진 → 압력계 상태·부식 의심 위치 → 확인 필요 항목 → 담당자 확인·정정 → 점검 기록 작성.
촬영 불충분이면 재촬영을 요청한다. 법정 자체점검 전체의 자동 합격 판정이나 소화기 작동 보장을 제공하지 않는다.

## 모델링과 범위

- 직접 상태 라벨이 있는 gauge_good/gauge_bad를 첫 실험으로, rust를 두 번째 대상으로 검증한다.
- 부품 검출 → 압력계 크롭 분류와 상태별 통합 검출을 비교한다. 사전학습 가중치를 미세조정한다.
- 핀·호스는 존재 확인 보조 기능이다. 미검출을 누락/고장으로 단정하지 않는다.
- 날짜 OCR은 정답 데이터가 검증되지 않았으므로 필수 범위에서 제외한다.
- 데이터 v18은 640×640. 더 큰 1024 입력이 사라진 세부 정보를 복원하지는 않으므로 우선 640으로 기준선을 만든다.
- 공개 split의 영상 프레임 혼합을 확인했다. 원본 영상/개체 그룹으로 재분할하고 그 결과를 자체 평가로 명시한다.
- 데이터 증강은 그룹 분할 이후 학습 데이터에만 적용한다. 독립 촬영 수와 증강 후 수를 분리 보고한다.
- 감지 점수 자체를 곧바로 이미지 전체 결함 확률로 사용하지 않는다. 집계·보정과 이미지 단위 정답 정의 후 #9 CLI에 연결한다.
- 사진상 항목별 이상을 평가하며 y_true=1은 해당 항목 이상이다. 기존 compliant 문자열이 법적 준수를 뜻하지 않도록 UI·문서를 수정한다.

## 완료 기준

클래스별 재현율·놓침률·검토율·오경보율과 분모를 보고한다. 작은 시험셋에서 1% 상한을 현장 보장치로 주장하지 않는다.
사진 촬영 일반화는 별도 검증 전에는 미확인이다. 검토 부담·기록 시간 감소를 AX 결과로 제시한다.
사진 점검 기술 자체는 기존 연구가 있으므로 완전히 새로운 발명이라고 발표하지 않는다.

## 현재 구현

평가 CLI·서버·Flutter 앱 골격을 재사용한다. 실제 Weqaa 로더/학습 모델은 아직 없다.
기존 facilities.json의 8종/24종 설정은 이번 소화기 단일 MVP의 데이터 매핑으로 사용하지 않는다.
AI Hub 데이터는 미국 AWS로 전송하지 않는다. 데이터·가중치·키는 Git에 넣지 않는다.
