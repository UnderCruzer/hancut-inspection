2026-09-27 기준 (#12 범위, #16 정의, D11 최종 정리). 이전 설계는 git 기록에 있다.

**E1–E5 는 줄이지 않는다.** E6 은 시간이 남을 때만 한다.

|----|------|------|------|----------|
| E1 | 박스 점수를 품목별 이미지 점수로 어떻게 바꾸나 | 최댓값 vs 보정된 집계 | 품목별 PR 곡선, 보정 오차 | 필수 |

## 지표 규약

**예측기 단독 성능(mAP)은 결론이 아니다.** 보고하되 그것으로 주장하지 않는다.

주 지표는 **놓침률 상한 하의 자동 처리율**이다. 상한을 먼저 고정하고, 그 조건에서
`auto_compliant` + `auto_noncompliant` 로 빠지는 비율을 본다. 나머지가 사람이 봐야 할 `review` 다.

`y_true=1` 은 "해당 품목 있음", `score` 는 `p(품목 있음)` 이다. 이 규약은 바꾸지 않는다.
분모를 항상 같이 적는다.

## 각 실험의 함정

**E1** — 여기서 잘못 정의하면 이후가 전부 무의미하다. 검출 점수는 보정돼 있지 않다.
최댓값을 확률처럼 쓰면 임계값이 데이터셋에 과적합된다. 검증셋과 시험셋을 반드시 분리한다.

**E2** — 측정 한계를 먼저 쟀다(2026-09-27). `1/N` 은 표현 가능한 하한일 뿐이고,
비율 추정에는 10건 이상이 필요하므로 **`10/N` 이 실질 하한**이다.

| 상한 | 신뢰성 있게 측정 가능한 품목 |
|---|---|
| 5% · 2% | 12종 전부 |
| **1%** | 12종 전부. Baton 이 1.17% 로 가장 빠듯하다 |
| 0.5% | 6종 (Powerbank·Hammer·Scissors·Pliers·Knife·Wrench) |
| 0.1% | 없음 |

주 격자는 **5·2·1%** 다. 0.5% 는 가능한 6종만 따로 보고한다.
**0.1% 는 어느 품목도 검증할 수 없으므로 시도하지 않는다.** 품목별 양성 수는 `ml/configs/items.json` 에 있다.
`zones.py` 는 놓침률 상한을 오경보 상한보다 우선한다 — `high` 는 `low` 아래로 내려가지 않으므로
오경보 상한이 적용되지 않을 수 있다. 표에 그 사실을 함께 적는다.

**E3** — 품목별로 쪼개면 각 층의 표본이 줄어 임계값이 불안정해진다.
자동 처리율이 올라도 그 차이가 표본 변동 안쪽이면 이득이라고 말하지 않는다.
탄약·수갑처럼 표본이 적은 품목은 따로 표시한다.

**E5** — 난이도 라벨은 **시험셋에만** 있다. 학습셋은 `xray_#####.png` 로 구분이 없으므로 시험셋에서만 본다.

구조를 실측했다. easy 와 hidden 은 **이미지당 정확히 1종**이고 hard 만 2.08종이다.
즉 hard 는 겹쳐서 어렵고 **hidden 은 숨겨서 어렵다.** 서로 다른 종류의 어려움이다.

| split | 이미지 | 양성 합계 | 이미지당 품목 |
|---|---:|---:|---:|
| easy | 9,482 | 9,482 | 1.00 |
| hard | 3,733 | 7,763 | 2.08 |
| hidden | 5,005 | 5,005 | 1.00 |

중요한 것은 **"상한을 지키려면 재검률을 얼마나 올려야 하는가"** 이지 hidden 성능이 나쁘다는 사실 자체가 아니다.

**품목 × 난이도로 쪼개지 않는다.** hidden 의 Baton 이 201장이라 5% 가 한계다. 난이도별은 품목을 합쳐서 본다.

**E6** — 재검 예산을 맞추지 않으면 더 많이 넘기는 쪽이 당연히 이긴다. 같은 예산에서만 비교한다.
판독관 시뮬레이션이 필요하므로 **주 결론에 넣지 않는다.** 부가 실험으로 보고한다.

## 성능 정의 — 교안의 다섯 단계

| 단계 | 이 프로젝트 |
|------|-------------|
| 정의 | 판독관이 봐야 할 사진 수를 줄인다. 단, 놓쳐서는 안 된다 |
| 측정 | 놓침률 상한별 자동 처리율·재검률·오경보율. 분모를 항상 같이 |
| 정답지 | PIDray 라벨. 비교 좌표로 인간 판독관 80~90%(EU JRC)를 인용 |
| 개선 | 이미지 점수 정의 → 품목별 임계값 → 장비별·난이도별. 한 번에 하나씩 |
| 재현 | 시드·서브셋 목록·임계값 JSON 을 커밋. 장비 교차가 재현 점검을 겸한다 |
