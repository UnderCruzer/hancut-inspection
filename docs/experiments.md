# 실험 설계

2026-09-24 범위 전환(#12) 기준. 이전 설계는 `docs/archive-weqaa/`, `docs/archive-aihub/`에 있다.

결과물은 앱이 아니라 아래 질문들의 답이다. 일정이 밀리면 **E5와 E6 중 하나만** 하고,
**E1–E4는 줄이지 않는다.** 이 넷이 결론을 만드는 축이다.

| ID | 질문 | 방법 | 지표 | 우선순위 |
|----|------|------|------|----------|
| E1 | 박스 점수를 어떻게 이미지 한 장의 점수로 바꾸나 | 최댓값 vs 보정된 집계. 검증셋에서 비교 | 놓침률 곡선, 보정 오차 | 필수 |
| E2 | 놓침률을 지키며 얼마나 자동화되나 | 상한 1·0.5·0.1%별 임계값 탐색 | 자동화율, 재검률, 오경보율 | **필수 · 핵심** |
| E3 | 품목별 임계값이 단일 임계값보다 나은가 | 품목별 탐색 vs 전체 하나. 같은 시험셋 | 같은 놓침률에서의 자동화율 차이 | 필수 |
| E4 | 장비가 바뀌면 임계값을 다시 잡아야 하나 | 장비 A에서 확정한 임계값을 B·C에 그대로 적용 | 장비별 놓침률 변화폭 | **필수 · 차별점** |
| E5 | 가려진 물품에서 운영점이 무너지나 | OPIXray 가림 난이도별 평가 | 난이도별 놓침률 | 선택 |
| E6 | 재검 사유를 제시할 수 있나 | 재검 구간에 볼 위치·품목 후보 제시 | 제시 정확도, 판독 시간 | 선택 |

## 각 실험의 함정

**E1** — 여기서 잘못 정의하면 E2 이후가 전부 무의미해진다. 검출 점수는 보정돼 있지 않다.
최댓값을 그대로 확률처럼 쓰면 임계값이 데이터셋에 과적합된다. 검증셋과 시험셋을 반드시 분리한다.

**E2** — 시험셋이 작으면 놓침률 0.1%를 **측정할 수 없다**. 양성 표본 1,000장이면 한 장을 놓쳐도 0.1%다.
상한별로 몇 장의 양성이 필요한지 먼저 계산하고, 측정 불가능한 상한은 표에 "측정 불가"로 적는다.

**E3** — 품목별로 쪼개면 각 층의 표본이 줄어 임계값이 불안정해진다.
자동화율이 올라도 그 차이가 표본 변동 안쪽이면 이득이라고 말하지 않는다.

**E4** — 장비별 장수가 크게 다르면 놓침률 변화가 장비 차이인지 표본 수 차이인지 구분되지 않는다.
장비별 장수를 맞춘 비교를 함께 보고한다.

## 성능 정의 — 교안의 다섯 단계

| 단계 | 이 프로젝트 |
|------|-------------|
| 정의 | 놓침률 상한을 지키며 판독관 확인 비율 최소화 |
| 측정 | 시험셋에서 놓침률·재검률·오경보율·자동화율 (`ml/hancut/eval/zones.py`). 분모를 항상 같이 적는다 |
| 정답지 | PIDray/SIXray 라벨 + 인간 판독관 80~90%(EU JRC) 기준선 |
| 개선 | 이미지 점수 정의 → 품목별 임계값 → 장비별 임계값. 한 번에 하나씩 |
| 재현 | 시드·서브셋 목록·임계값 JSON을 커밋. 장비 교차가 재현 점검을 겸한다 |
