# 실험 설계

2026-09-24 기준 (#12 범위 전환, #16 과제 재정의). 이전 설계는 `docs/archive-*/`.

결과물은 앱이 아니라 아래 질문들의 답이다. **E1–E4 는 줄이지 않는다.** E5 와 E6 중 하나만 한다.

| ID | 질문 | 방법 | 지표 | 우선순위 |
|----|------|------|------|----------|
| E1 | 박스 점수를 품목별 이미지 점수로 어떻게 바꾸나 | 최댓값 vs 보정된 집계 | 품목별 PR 곡선, 보정 오차 | 필수 |
| E2 | 고정 임계값으로는 어디까지 되나 | `zones.py` 임계값 탐색 | 위임 예산별 시스템 놓침률 | 필수 · 기준선 |
| E3 | 학습된 위임기가 E2 를 이기나 | L2D surrogate 학습, 같은 위임 예산에서 비교 | 시스템 놓침률 차이 | **필수 · 핵심** |
| E4 | 판독관 가정이 위임 규칙을 얼마나 바꾸나 | 정확도 80/90% × 난이도 조건부/균일 | E3 결론의 뒤집힘 여부 | **필수 · 가장 흥미로움** |
| E5 | 장비가 바뀌면 다시 학습해야 하나 | 장비 A 학습 → B·C 적용 | 장비별 놓침률 변화폭 | 선택 |
| E6 | 난이도별 위임 예산 차등이 낫나 | easy/hard/hidden 별 예산 배분 | 같은 총예산에서의 놓침률 | 선택 |

## 지표 규약

**예측기 단독 성능(mAP, 정확도)은 결론이 아니다.** 보고하되 그것으로 주장하지 않는다.

주 지표는 **위임 예산 b 에서의 시스템 놓침률**이다. 사진의 b 비율을 사람에게 넘기고
나머지를 모델이 판정했을 때, 사람과 모델을 합친 결과에서 품목을 놓친 비율이다.
b 를 0부터 1까지 훑은 곡선으로 기준선들을 비교한다. b=0 은 "항상 모델", b=1 은 "항상 사람"이다.

분모를 항상 같이 적는다. `y_true=1` 은 "해당 품목 있음", `score` 는 `p(품목 있음)` 이다. 이 규약은 바꾸지 않는다.

## 각 실험의 함정

**E1** — 여기서 잘못 정의하면 이후가 전부 무의미하다. 검출 점수는 보정돼 있지 않다.
최댓값을 확률처럼 쓰면 임계값이 데이터셋에 과적합된다. 검증셋과 시험셋을 반드시 분리한다.

**E2** — 시험셋이 작으면 낮은 놓침률은 **측정할 수 없다**. 품목별 양성이 1,000장이면 한 장을 놓쳐도 0.1% 다.
품목별 양성 장수를 먼저 세고, 측정 불가능한 구간은 표에 "측정 불가"로 적는다.

**E3** — L2D 가 이기는 것처럼 보이는 가장 흔한 이유는 **비교가 불공정해서**다.
위임 예산을 맞추지 않으면 더 많이 넘기는 쪽이 당연히 이긴다. 같은 b 에서만 비교한다.
또 위임기가 예측기와 같은 특징을 쓰면 "모델이 모르는 것"만 넘기고 "사람이 잘하는 것"은 못 넘긴다.

**E4** — 여기서 E3 의 결론이 뒤집힐 수 있다. **뒤집히면 그것을 결과로 보고한다.**
모델과 사람이 같은 것을 틀리면 위임은 이득이 없다. 그 조건을 찾는 것이 목적이지, 이기는 것이 목적이 아니다.
판독관 가정을 최소 네 가지로 돌린다.

**E5** — 장비별 장수가 다르면 변화가 장비 차이인지 표본 수 차이인지 구분되지 않는다. 장수를 맞춘 비교를 함께 낸다.
**장비 메타데이터가 파일에 없으면 이 실험은 성립하지 않는다.** #14 에서 먼저 확인한다.

## 판독관 시뮬레이터

E3·E4 의 입력이자 이 프로젝트의 최대 한계다. 별도 모듈로 만들고 테스트를 붙인다.

- 입력: 정답 라벨, 난이도(easy/hard/hidden), 품목
- 출력: 그 판독관이 내놓았을 판정
- 파라미터: 전체 정확도 목표치, 난이도별 배분, 놓침/오경보 비대칭
- 시드를 고정하고 설정을 JSON 으로 커밋한다. 재현의 핵심이다

난이도 라벨이 학습셋에 없을 수 있다. 그 경우 학습 구간의 난이도를 어떻게 정의할지 #14 이후에 정한다.

## 성능 정의 — 교안의 다섯 단계

| 단계 | 이 프로젝트 |
|------|-------------|
| 정의 | 사람과 모델의 분업을 설계한다. 합친 성능이 지표다 |
| 측정 | 위임 예산별 시스템 놓침률 곡선. 기준선 5개와 함께 |
| 정답지 | PIDray 라벨 + 시뮬레이션 판독관(EU JRC 80~90% 기준) |
| 개선 | 이미지 점수 정의 → 고정 임계값 → 학습된 위임기 → 판독관 가정. 한 번에 하나씩 |
| 재현 | 시드·서브셋 목록·시뮬레이터 설정·임계값 JSON 을 커밋 |
