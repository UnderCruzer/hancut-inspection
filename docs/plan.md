# 한컷점검 — 보안검색 X-ray 판정 운영점 (1인)

2026-09-24 범위 전환(#12). 이전 계획은 `docs/archive-weqaa/plan.md`에 있다.

## 한 문장

보안검색 X-ray 사진을 놓침률 상한 아래에서 **자동통과 / 재검 / 자동적발** 세 구간으로 나눠,
판독관이 직접 봐야 할 가방을 몇 %까지 줄일 수 있는지 정한다.

## 무엇이 기여인가

탐지 모델은 포화 영역이다. YOLO 계열 개선부터 VLM까지 나와 있고, 여기서 새 탐지기를 만들지 않는다.
**사전학습 검출기를 그대로 쓰고, 그 출력을 운영 가능한 판정으로 바꾸는 부분**이 이 프로젝트의 몫이다.

구체적으로 세 가지 질문에 답한다.

1. 놓침률을 1% / 0.5% / 0.1%로 묶으면 각각 몇 %를 자동 처리할 수 있는가
2. 품목별로 임계값을 따로 잡으면 전체 하나로 잡을 때보다 자동화율이 오르는가
3. **장비가 바뀌면 임계값을 다시 잡아야 하는가** — PIDray 장비 3종으로 실측한다

3번이 실무에서 가장 중요하고, 확인한 범위에서 아직 답이 없는 질문이다.

## 교안 5단계 대응

| 단계 | 이 프로젝트에서 |
|---|---|
| 정의 | 판독관이 봐야 할 가방 수를 줄인다. 단, 놓쳐서는 안 된다 |
| 측정 | mAP가 아니라 놓침률·오경보율·재검률·자동화율. 분모를 항상 같이 보고한다 |
| 정답지 | PIDray/SIXray 라벨 + 인간 판독관 80~90%(EU JRC) 기준선 |
| 개선 | 품목별·장비별 임계값 분리 |
| 재현 | 장비 교차 검증, seed 고정, 스크립트 한 줄 실행 |

## 실험

| 코드 | 내용 | 필수 |
|---|---|---|
| E1 | 박스 점수 → 이미지 단위 점수 정의. 최댓값 vs 보정 집계 비교 | 필수 |
| E2 | 놓침률 상한별 3구간 운영점. `zones.sweep()` | 필수 |
| E3 | 품목별 임계값 분리 vs 단일 임계값 | 필수 |
| E4 | 장비 교차 — A에서 잡은 임계값을 B/C에 적용했을 때의 놓침률 변화 | 필수 |
| E5 | 가림 난이도별 운영점 (OPIXray 보조) | 선택 |
| E6 | 재검 사유 제시 — 판독관에게 볼 위치를 알려준다 | 선택 |

**E5와 E6 중 하나만 한다.** 혼자 하므로 범위를 줄인다. D6과 같은 이유다.

## 완료 기준

품목별·장비별 놓침률·재검률·오경보율·자동화율을 분모와 함께 보고한다.
시험셋이 작으면 그 사실을 적고, 작은 표본의 1% 상한을 현장 보장치로 주장하지 않는다.

## 하지 않을 주장

**새로운 탐지기를 발명했다고 말하지 않는다.** 탐지는 기존 연구가 충분하고, 그걸 쓴다.

**TSA/ECAC의 실제 요구 수치는 비공개다**(보안민감정보). 상한을 고정값으로 박지 않고 파라미터로 두고 스윕한다.
발표에서 "규정 수치가 비공개라 여러 상한에서의 운영점을 제시한다"가 정확한 표현이다.

**실제 공항 운영에 쓸 수 있다고 말하지 않는다.** 공개 벤치마크에서의 운영점 분석이다.
SIXray는 지하철역에서 수집됐다. "공항"으로 한정해 말하지 않는다.
